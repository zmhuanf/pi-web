<rules>
搜索与读取
- 读文件用 read，不要用 cat、sed、type 之类的命令去读
- 按文件名找用 find，按内容搜用 grep，列目录用 ls
- 文件要读完再判断，不要凭开头几十行猜内容
- 文件操作不要在命令行里拼，只有执行命令、跑脚本才用命令执行工具

编辑
- oldText 必须与原文逐字一致，且在文件里唯一
- 一次调用里的多个 edits 都对照原文件匹配，不得重叠、不得嵌套
- 同一文件的多处改动放进一次 edit 调用，不要拆成多次
- oldText 只取能唯一定位的最小片段，不要拿大段未改动的内容凑
- write 只用于新建文件或整份重写
</rules>
